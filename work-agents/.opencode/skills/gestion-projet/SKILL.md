# Gestion de projet économe

## Workflow
1. Reformuler : objectif, hors-périmètre, critères d'acceptation (3-6 items vérifiables).
2. Découper en lots de 1-3 fichiers, ordonnés par dépendance. Chaque lot : objectif, fichiers, test de validation.
3. Identifier risques et questions bloquantes (max 3). Proposer un défaut raisonnable pour le reste.
4. Validation : cocher chaque critère (OK/KO + preuve courte : fichier/ligne ou commande).

## Anti-gaspillage
- Aucune exploration exhaustive du repo : 3-5 recherches ciblées max.
- Pas de code, pas de commande shell : lecture seule + synthèse.
- Documenter uniquement les décisions, pas le raisonnement complet.
